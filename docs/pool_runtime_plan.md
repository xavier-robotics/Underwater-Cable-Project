# 水池现场识别方案

## 目标

中期检查以现场可检出为第一目标：输入水池相机视频或实时画面，输出海缆位置框或 mask。类别细分可以作为加分项，但现场演示优先保证“看到海缆并稳定检出”。

## 主方案：SAM 提示式检出

SAM 不能凭空知道“海缆是什么”，需要点、框或前序检测器提示。现场水池环境相对可控，因此推荐：

1. 第一帧人工点选海缆中心点，或给一个覆盖海缆的框。
2. SAM 输出海缆 mask。
3. 后处理保留细长、连续、面积合适的 mask，转成 bbox。
4. 后续帧用上一帧 bbox 扩大 10%-30% 作为下一帧 SAM prompt。
5. 若连续若干帧失败，再要求人工重新点选或退回 OpenCV 兜底。

优点：样本少也能跑，适合中期现场演示。缺点：速度比 YOLO 慢，对初始 prompt 有依赖。

## 备选方案：YOLO 检测

用 SAM 辅助标注 100-200 张 1080p 图片，然后训练 YOLO 检测器。现场运行时 YOLO 更快、更自动，但小样本下泛化风险更高。

建议训练策略：

- 先只做 `cable` 单类检测，确保能检出。
- 三分类状态作为第二阶段：触底完好、破损、悬空完好；破损类别不再区分位置。
- 增强重点放在亮度、对比度、模糊、浑浊、裁剪、旋转。
- 训练集至少覆盖水池现场相机角度和光照。

## 兜底方案：OpenCV 细长目标检出

`scripts/runtime_detect.py --method opencv` 不依赖深度模型，通过边缘、形态学闭运算和长宽比过滤找细长目标。它不如 SAM/YOLO 准，但可以作为现场兜底，证明程序链路可跑。

快速验证前 300 帧：

```bash
conda run -n yoloe python scripts/runtime_detect.py \
  --input /home/nvidia/DATA/UW/video \
  --output-dir outputs/runtime_opencv_preview \
  --method opencv \
  --sample-stride 5 \
  --max-frames 300
```

## 近期任务清单

1. 在 `data/frames_1080p` 中选 80-120 张水池代表帧。
2. 用 SAM 给海缆主体做 mask，先标单类 `cable`。
3. 从 mask 转 bbox，训练一个单类 YOLO baseline。
4. 准备现场脚本：
   - SAM prompt 模式：初始点/框 + 后处理。
   - YOLO 模式：自动检测。
   - OpenCV 模式：兜底检测。
5. 用原视频离线跑 `outputs/runtime`，检查误检和漏检。

## 现场验收口径

若老师要求准确率，建议报告两个层次：

- 检出率：有海缆帧中成功检出海缆的比例。
- 定位质量：预测框和人工框 IoU 大于 0.5 的比例。

状态分类准确率等数据量上来后再做，不作为当前现场演示的唯一指标。
